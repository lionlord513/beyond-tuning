# Beyond Tuning 1.0.0

Adds Car Tuning to in-game computers using the native window approach established by Beyond Apocalypse's Hangar app.

- Seven live gauges and a 15-second telemetry graph.
- Five working calibration controls and an interpolated 5-by-8 torque correction table.
- Automatic last-car selection and installed-engine identification.
- Transparent, rotatable engine hologram with attached parts, drag/orbit controls, tilt, zoom and Top view; all 21 engine types checked.
- Individual native turbo boost settings and optional BA nitrous injection strength/duration tuning.
- Standalone operation without BA, with nitrous clearly marked unavailable.
- Stock restoration, draft/revert workflow, immediate persistent car/engine calibrations, backup recovery and per-save snapshots.
- Stock, Street and Economy presets, permanent JSON import/drop library, automatic Last applied presets and export dialog.
- Built-in Help, Classic/Dark themes, colors, speed units and Simple view.
- Beyond Mod Manager package metadata, preservation rules and GitHub release updates.

Host-only tuning application. Multiplayer replication has not been tested in a separate two-player session. Tested game version: build 26106988, with Beyond Apocalypse 1.0.10.
